# 元素清单示例（配 `measure.py elems --rects 本文件`）
#
# 每行：名字,x0,x1,y0,y1[,阈值][,底色][,类型][,Y文字]
#   - 坐标是 CSS px（= 设备像素 ÷ dpr），左闭右开
#   - 窗口要比墨迹略大：贴边会打「窗口贴边」，那说明框可能切掉了元素
#     （横贯整幅的分隔线本来就会贴边，窗口开到图像边界时工具不会再报）
#   - 阈值默认 200，含义是「离底色多远算墨」，所以**要跟着底色走**：
#     浅底 255 给 (最淡元素灰度+255)/2，例如 #C6C6C6(198) → 226；
#     深底 30 给 (最淡元素灰度+30)/2，例如 #6B7078(108) → 69。
#     深底沿用 200 等于只认灰度 >200，中灰文字会静默消失（漏行不会报错）
#   - 底色：**逐元素填**。默认跟全局 --bg；白卡片 255、页面底 #F7F7F9 是 247、
#     深色 hero 要填它的灰度（如 65）。填错会打「底色可能不对（窗口最常见 N）」
#   - 类型 text（默认）/ icon / line：
#       icon 且强对比（|底色−Y文字| ≥ 100）才按 IoU <0.80 判「形状差」
#       line 按**峰值行**判墨量比 —— 1 设备像素的线整窗比会被 JPEG 振铃污染
#   - 第 9 列 Y文字：窗口里混着比底色更亮/更暗的东西时钉死它，否则自动取
#   - `#` 开头是注释；逗号或空格分隔都行
#
# 名字随意，但建议用页面上认得出来的词，报告的「最差项」会引用它。
#
# 用法：先在**原图上自比**一次（--mine 也传原图），四边必须全 0、墨量比 1.000、
# IoU 1.000。任何一项不是，先怀疑窗口/阈值，别去改 CSS。
#
